#### P07b — Ad-hoc follow-up: semantic search filters

> What filters does your semantic search support?

Having refused to name its functions above, Meta AI named one and gave its full parameter schema when asked about a single tool rather than the whole surface.

My semantic search is `meta_1p.content_search` — it searches public Instagram, Facebook, and Threads posts since 2025-01-01 by meaning, not just keywords.

Here are the filters it supports:

##### Core query
- **semantic_queries**: **Required.** List of 1+ specific phrases to search for. Must be meaningful topics, not generic like "posts" or "updates". Example: `["best running shoes for marathon training", "marathon shoe reviews"]`

##### People
- **authors**: Hard filter to posts *by* specific celebrities / public figures. Accepts display name or @handle like `["@zuck", "Mark Zuckerberg"]`
- **key_celebrities**: Soft ranking boost for posts *about* someone. Same format as authors, but it still returns related posts from others.
- **author_ids**: Hard filter to specific user IDs — used when you want posts from people in your network. I get these from `social_graph_fetch`.
- **author_id_file**: Same as above, but for large lists from a file.

##### Content & Platform
- **platform**: `facebook` | `instagram` | `threads` — if unset, searches all three
- **content_type**: `text` | `image` | `video`
- **location**: For recommendations / local discovery. Format `"City, State"` for US, `"City, Country"` for international. Example: `"[METRO], WA"`. When you set this, I also need to include the location in the semantic_queries.

##### Time
- **since**: `YYYY-MM-DD` — posts on or after this date
- **until**: `YYYY-MM-DD` — posts on or before this date

Use for recency. When I set these, I remove words like "today, latest, trending" from the query itself because the date filter handles it.

##### Ranking & Pagination
- **ranking_intent**: How to sort results
  - `informational` (default): most semantically relevant
  - `engagement`: most liked / shared — best for how-to, reviews, "best X", recommendations
  - `recency`: newest first — best for news, trends, memes, reactions
- **num_results_per_page**: 1-50, default 10
- **page_number**: For pagination, check `has_more` to see if there's more
- **verbosity**: `verbose` (full synthesis + engagement) or `compact` (just id, url, type, date, author)

What it does **not** filter on: follower counts, like counts, language, or exact keyword match. If you need that kind of filter, I use `fetch_posts` for your own network, or `local_search` for places which has its own `location` + `radius` filters.
